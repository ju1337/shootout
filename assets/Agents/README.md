# Agentenmodelle (Kopien für die automatische Prüfung)

Hier liegen Kopien der fertigen Agentenmodelle als `.rbxmx`, meist ganze Charaktere aus dem Avatar-Setup von
Studio. So kommt eine Kopie hierher: in Studio Rechtsklick auf das Modell unter ReplicatedStorage › Assets › Agents
› „Save to File…“ › als `<Agent>.rbxmx` speichern (z.B. `Viper.rbxmx`) und auf GitHub hier hochladen
(Add file › Upload files).

Das Spiel selbst lädt die Modelle aus dem Place. Die Kopien hier prüft GitHub bei jedem Push (Test `agentassets`).
Anleitung: [docs/agenten-modelle.md](../../docs/agenten-modelle.md)
