# Agentenmodelle (Kopien für die automatische Prüfung)

Hier liegen Kopien der fertigen Agenten-Ausrüstung als `.rbxmx`: in Studio Rechtsklick auf das Modell unter
ReplicatedStorage › Assets › Agents › „Save to File…“ › hier als `<Agent>.rbxmx` speichern (z.B. `Viper.rbxmx`).

Das Spiel selbst lädt die Modelle aus dem Place. Die Kopien hier prüft GitHub bei jedem Push (Test `agentassets`).
Anleitung: [docs/agenten-modelle.md](../../docs/agenten-modelle.md)
